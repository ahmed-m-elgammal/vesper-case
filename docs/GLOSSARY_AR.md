# Arabic Glossary — Ink & Ashes (اللغة العربية الفصحى المبسطة)

Localization glossary for the MSA (Modern Standard Arabic) localization.
Rules agreed with the translation brief: translate meaning and voice, never
word-for-word; Arabic punctuation (، ؟ ؛ « ») ; keep placeholders (`{0001}`,
`{param}`) exactly; respect speaker/listener gender; keep UI strings short.

## Style rules (all strings)

- Register: simple, natural literary MSA — the voice of Arabic crime fiction,
  not stiff formal prose. Idioms are re-authored, not transliterated
  (e.g. "It doesn't add up" → «هذا لا يستقيم»).
- Em dashes (`--` in source) render as « — ». Quotes use « ». Question mark ؟,
  comma ،, semicolon ؛.
- Times/dates keep Western digits (10:47، 1949) — the notebook art and gates
  use them.
- Spoken clock times: العاشرة والنصف · العاشرة والربع · الإحدى عشرة إلا عشرين ·
  الإحدى عشرة والنصف · منتصف الليل إلا ربعًا.
- Gender: detective Elias Byrne is male («سيدي» from NPCs); Colette/Peggy/Quill
  are addressed with feminine verbs by the player; suspect lines agree with the
  speaker's own gender.
