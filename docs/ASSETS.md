## 3. UI chrome

- **Fonts** (bundled via `@fontsource`, OFL): `Caveat 500/700` (handwriting), `Special Elite 400` (typewriter/case file), `Crimson Pro 400/400i/600/700` (body serif).
- **PWA icons** (generated by `scripts/gen_icons.py`, PIL): `public/icons/icon-192.png`, `public/icons/icon-512.png`, `public/icons/maskable-512.png` — magnifier-on-paper motif.
- **Textures**: none (no sprite sheets needed for Build One — SVG layers rasterize directly). Budget per room ≈ 3 layers × 8.6 MB decoded, released on scene shutdown.
